## Command Template

# UI Review Checklist

Review the changed UI for:

## UX
- Is the primary task obvious?
- Are controls contextual?
- Is direct manipulation available?
- Are states clear?
- Are cancellation and error paths reasonable?

## Visual
- Does it look like professional desktop software?
- Is hierarchy clear?
- Is density appropriate?
- Are borders/cards/shadows overused?
- Are alignment and spacing consistent?
- Are selected and focused states obvious?

## egui
- Is repainting controlled?
- Is state ownership clear?
- Are custom widgets reused?
- Is the hot path lightweight?

## Video editor
- Does the behavior match editing expectations?
- Does selection drive the inspector appropriately?
- Does timeline behavior preserve temporal context?
- Is undo/redo considered?
