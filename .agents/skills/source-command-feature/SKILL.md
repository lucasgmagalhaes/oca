# source-command-feature

Use this skill when the user asks to run the migrated source command `feature`.

## Command Template

# Feature Workflow

For a non-trivial feature:

1. Identify relevant domain object(s).
2. Read applicable UX and engineering guidance.
3. State the user workflow and interaction states.
4. Propose minimal architecture changes.
5. Implement in small cohesive modules.
6. Add/update tests.
7. Run quality gates.
8. Perform visual and interaction review.

Do not skip directly from feature request to a giant code change.
