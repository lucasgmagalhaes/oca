# Avoiding AI-Generated UI Aesthetics

Do not default to:
- oversized headings;
- excessive empty space;
- large pill buttons;
- every section inside a rounded card;
- arbitrary gradients;
- decorative blobs;
- excessive shadows;
- uniform layouts that ignore task importance;
- icon-only controls without discoverability.

Prefer:
- dense but breathable information layouts;
- clear alignment systems;
- purposeful separators;
- restrained emphasis;
- task-oriented panels;
- contextual controls;
- strong selected states;
- visual quiet around the primary workspace.

Before adding a container, ask whether it communicates grouping better than spacing or alignment alone.

Before adding a control, ask whether it belongs in the current context.
