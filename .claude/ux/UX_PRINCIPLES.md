# UX Principles

## Context over permanence
Show controls when they are relevant to the selected object or active workflow.

## Direct manipulation
Prefer dragging, trimming, handles, inline controls and context menus over wizard-like flows.

## Progressive disclosure
Basic operations should be easy to discover. Advanced operations should not permanently clutter the workspace.

## Preserve focus
Avoid unnecessary dialogs and workflow interruptions.

## Spatial consistency
Panels, tools and feedback should remain predictable across sessions.

## Long-session ergonomics
The editor is used for extended periods. Avoid excessive visual noise, large travel distances and tiny precision targets.

## State clarity
Users should always understand:
- what is selected;
- where the playhead is;
- whether an operation is previewing or committed;
- whether changes are saved;
- what keyboard focus currently means.

## Fast feedback
Interactive actions should visibly respond immediately, even if expensive work continues asynchronously.
